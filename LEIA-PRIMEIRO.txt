MULT SILK CAMISETAS — NOVO PAINEL + ATENDENTE COM IA

1. Esta atualização é testada na branch melhorias-painel-ia.
2. Quando aprovada, mescle a pull request na main.
3. Vercel Settings > Environment Variables: ADMIN_PASSWORD (12+ caracteres), SESSION_SECRET (32+ caracteres) e GITHUB_TOKEN (fine-grained apenas para este repositório com Contents Read and write).
4. Para ativar IA, adicione OPENAI_API_KEY. A API OpenAI tem cobrança separada do ChatGPT.
5. Redeploy na Vercel após salvar as variáveis.

Não divulgue senhas e tokens no GitHub ou no chat. Consulte README.md.
